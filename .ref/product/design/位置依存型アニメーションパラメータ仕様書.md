# 位置依存型アニメーションパラメータ仕様書

## 1. 機能概要

### 1.1 目的
キャラクター（catA, catB）の落下アニメーションにおいて、最終落下位置（Y座標）に応じて揺れパラメータとバウンドパラメータを動的に変化させることで、より自然で物理的に説得力のあるアニメーションを実現する。

### 1.2 適用範囲
- 対象キャラクター: catA, catB
- 対象デバイス: mobile-portrait, mobile-landscape, tablet-portrait, tablet-landscape, desktop
- 対象モード: ライトモード、ダークモード
- 影響を受ける要素: スポットライト位置（ダークモード時）

### 1.3 基本原則
下に落下するほど（Y座標が大きいほど）：
- 揺れの周波数が小さくなる（ゆっくり揺れる）
- 揺れの振幅が大きくなる（大きく揺れる）
- バウンド係数が大きくなる（大きく跳ねる）

## 2. 詳細仕様

### 2.1 パラメータ定義

#### 2.1.1 基本パラメータ
| パラメータ名 | 説明 | 単位 | 既定値 |
|------------|------|-----|--------|
| `finalPositionY` | 最終落下位置のY座標 | px | キャラクターごとに異なる |
| `amplitude` | 揺れの振幅（横方向の揺れ幅） | px | 位置により変動 |
| `frequency` | 揺れの周波数（揺れの速さ） | - | 位置により変動 |
| `gravity` | 重力加速度 | px/frame² | 1.3（固定） |
| `bounceFactor` | バウンド係数（跳ね返りの強さ） | - | 位置により変動 |
| `baseOffsetX` | X方向のベースオフセット | px | 設定ファイルから取得 |
| `baseOffsetY` | Y方向のベースオフセット | px | 設定ファイルから取得 |

#### 2.1.2 デバイス別の初期落下高さ
| デバイス/向き | 初期Y座標 | 説明 |
|-------------|----------|------|
| portrait（縦向き） | -500px | スマホ・タブレット縦向き |
| landscape/PC | -1150px | スマホ・タブレット横向き、デスクトップ |

### 2.2 パラメータ変化式

#### 2.2.1 基準値の定義
portraitモードとlandscape/PCモードで基準値が異なるため、各モードごとに定義する。

##### Portrait モード（スマホ・タブレット縦向き）
```
基準Y座標範囲: 0px 〜 60px
基準amplitude範囲: 3.3px 〜 10px
基準frequency範囲: 0.01 〜 0.05
基準bounceFactor範囲: 0.7 〜 0.85
```

##### Landscape/PC モード
```
基準Y座標範囲: 50px 〜 50px (catA), 50px 〜 50px (catB)
※現在の実装ではcatAとcatBが同じfinalPositionYを持つが、将来的に異なる値を設定可能
基準amplitude範囲: 7px 〜 20px
基準frequency範囲: 0.01 〜 0.05
基準bounceFactor範囲: 0.7 〜 0.85
```

#### 2.2.2 Portrait モード用の変化式

##### Y座標の正規化
```
normalizedY = (finalPositionY - minY) / (maxY - minY)

where:
  minY = 0px
  maxY = 60px
  finalPositionY = キャラクターの最終落下位置
  normalizedY = 0.0（上端） 〜 1.0（下端）
```

##### Amplitude（振幅）の計算
```
amplitude = minAmplitude + (maxAmplitude - minAmplitude) * normalizedY

where:
  minAmplitude = 3.3px  (上端での最小振幅)
  maxAmplitude = 10px   (下端での最大振幅)

具体例:
  finalPositionY = 0px   → amplitude = 3.3px
  finalPositionY = 30px  → amplitude = 6.65px
  finalPositionY = 60px  → amplitude = 10px
```

##### Frequency（周波数）の計算
```
frequency = maxFrequency - (maxFrequency - minFrequency) * normalizedY

where:
  maxFrequency = 0.05   (上端での最大周波数 = 速い)
  minFrequency = 0.01   (下端での最小周波数 = 遅い)

具体例:
  finalPositionY = 0px   → frequency = 0.05
  finalPositionY = 30px  → frequency = 0.03
  finalPositionY = 60px  → frequency = 0.01
```

##### BounceFactor（バウンド係数）の計算
```
bounceFactor = minBounce + (maxBounce - minBounce) * normalizedY

where:
  minBounce = 0.7   (上端での最小バウンド)
  maxBounce = 0.85  (下端での最大バウンド)

具体例:
  finalPositionY = 0px   → bounceFactor = 0.70
  finalPositionY = 30px  → bounceFactor = 0.775
  finalPositionY = 60px  → bounceFactor = 0.85
```

#### 2.2.3 Landscape/PC モード用の変化式

##### Y座標の正規化
```
normalizedY = (finalPositionY - minY) / (maxY - minY)

where:
  minY = 50px
  maxY = 50px

※現在の実装では両キャラクターが同じfinalPositionY（50px）を持つため、
  normalizedYは常に不定形（0/0）となる。
  将来的にfinalPositionYを変更する場合は、minYとmaxYの範囲を適切に設定する。
```

##### 現在の実装（暫定）
現在はcatAとcatBで異なる固定値を使用：
```
catA:
  finalPositionY = 50px
  amplitude = 7px
  frequency = 0.05
  bounceFactor = 0.7

catB:
  finalPositionY = 50px
  amplitude = 20px
  frequency = 0.01
  bounceFactor = 0.7
```

##### 将来の拡張（例：finalPositionYが50px〜150pxの範囲の場合）
```
minY = 50px
maxY = 150px

amplitude = 7 + (20 - 7) * normalizedY
frequency = 0.05 - (0.05 - 0.01) * normalizedY
bounceFactor = 0.7 + (0.85 - 0.7) * normalizedY
```

### 2.4 スポットライト位置の連動

ダークモード時、キャラクターの位置に追従してスポットライトが配置される。

#### 2.4.1 スポットライト配列
```typescript
spotlightsRef.current = [mouseSpot, LLSpot, LRSpot]

where:
  mouseSpot: マウスカーソル位置のスポットライト（PC）
  LLSpot: catBに追従する左スポットライト
  LRSpot: catAに追従する右スポットライト
```

#### 2.4.2 スポットライト位置の計算
```typescript
// catAに対応する右スポットライト（spotlightR）
spotlightR.style.top = catARect.bottom - catARect.height * 0.5 + offsetTop
spotlightR.style.right = offsetRight

// catBに対応する左スポットライト（spotlightL）
spotlightL.style.top = catBRect.bottom - catBRect.height * 0.5 + offsetTop
spotlightL.style.left = offsetLeft
```

## 3. 実装の注意点

### 3.1 ダークモード切り替え時の挙動

#### 3.1.1 ライトモード → ダークモード
1. スポットライトキャンバスを初期化
2. キャラクターの現在位置を取得
3. スポットライト位置を計算・配置
4. `drawSpotlights()`を呼び出してスポットライトエフェクトを描画

#### 3.1.2 ダークモード → ライトモード
1. スポットライトキャンバスをクリア
2. スポットライト配列を空にする
3. 描画コールバックを解除

#### 3.1.3 実装コード例
```typescript
useEffect(() => {
  if (isDarkMode && !initialized) {
    initializeSpotlight();
  } else if (!isDarkMode) {
    if (ctx && canvas) ctx.clearRect(0, 0, canvas.width, canvas.height);
    spotlightsRef.current = [];
    updateSpotlightCallbackRef.current = null;
    initialized = false;
  }
  updatePosition();
}, [isDarkMode, windowSize, overlayVisible, updatePosition]);
```

### 3.2 向き切り替え時の挙動

#### 3.2.1 Portrait ⇔ Landscape 切り替え検知
```typescript
const handleResize = () => {
  const newDeviceKey = getDeviceConfigKey();
  const newIsPortrait = newDeviceKey.includes('portrait');

  // portrait状態が変わった場合のみ再調整
  if (newIsPortrait !== isPortrait) {
    // アニメーションを停止
    if (animationId !== null) cancelAnimationFrame(animationId);

    // パラメータをリセット
    velocity = 0;
    positionY = newIsPortrait ? -500 : -1150;
    isBouncing = true;
    angle = 0;

    // アニメーションを再開始
    animationId = requestAnimationFrame(startAnimation);
  }
};
```

#### 3.2.2 落下演出の再実行
向きが切り替わった際、以下の処理を実行する：
1. 現在のアニメーションをキャンセル
2. キャラクター位置を初期位置にリセット
3. 新しいデバイス設定（portrait/landscape）を取得
4. 新しいパラメータで落下アニメーションを再開

#### 3.2.3 スポットライト位置の更新
```typescript
// 毎フレームスポットライト位置を更新
element.style.transform = `translate(${swayOffset + baseOffsetX}px, ${positionY + baseOffsetY}px)`;
updatePosition(); // ← スポットライト位置も更新
```

### 3.3 パラメータ更新タイミング

#### 3.3.1 リアルタイム更新が必要な場面
- アニメーションの各フレーム（`requestAnimationFrame`内）
  - キャラクター位置の更新
  - スポットライト位置の更新（ダークモード時）

#### 3.3.2 イベント駆動で更新が必要な場面
- ウィンドウリサイズ時
- デバイスの向き変更時（`orientationchange`）
- ダークモード切り替え時
- ページ読み込み完了時

### 3.4 パフォーマンス最適化

#### 3.4.1 スポットライト描画の最適化
```typescript
// 移動距離が閾値（2px）以上の場合のみ更新
const dx = e.clientX - lastMousePosition.x;
const dy = e.clientY - lastMousePosition.y;
const distance = Math.sqrt(dx * dx + dy * dy);

if (distance < 2) return; // 閾値未満はスキップ

// requestAnimationFrameで描画を間引き
if (isAnimating) return;
isAnimating = true;

if (animationFrameId) cancelAnimationFrame(animationFrameId);
animationFrameId = requestAnimationFrame(() => {
  drawSpotlights(spotlightsRef.current);
  isAnimating = false;
});
```

#### 3.4.2 位置計算の最適化
- スポットライト位置は毎フレーム更新するが、DOM要素の取得は最小限にする
- `getBoundingClientRect()`の呼び出しを必要な時のみに限定
- `window.scrollX/Y`は一度だけ取得して再利用

### 7.3 デバイス判定ロジック
```typescript
const getDeviceConfigKey = () => {
  const isPortrait = window.innerHeight > window.innerWidth;
  const isTouchDevice = 'ontouchstart' in window || navigator.maxTouchPoints > 0;
  const width = window.innerWidth;
  const height = window.innerHeight;

  const shortSide = Math.min(width, height);
  const longSide = Math.max(width, height);

  if (shortSide <= 428) {
    return isPortrait ? 'mobile-portrait' : 'mobile-landscape';
  } else if (isTouchDevice && longSide <= 1280) {
    return isPortrait ? 'tablet-portrait' : 'tablet-landscape';
  } else {
    return 'desktop';
  }
};
```
