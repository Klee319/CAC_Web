## 1. 設計概要

### 1.1 設計目的

現在のwelcomeJS.tsxでは、キャラクター（catA, catB）のアニメーションパラメータ（amplitude, frequency, bounceFactor）が固定値としてハードコーディングされている。本設計では、仕様書に基づき、最終落下位置（finalPositionY）に応じてこれらのパラメータを動的に計算することで、より自然で物理的に説得力のあるアニメーションを実現する。

### 1.2 設計方針

1. **段階的実装**: Phase 1〜4に分けて段階的に実装し、各フェーズで動作確認を行う
2. **後方互換性**: 既存の動作を維持しつつ、新機能を追加する
3. **保守性**: パラメータは設定ファイルで管理し、コードの変更を最小限にする
4. **並列開発対応**: 各Phaseは独立性を持たせ、複数の開発者が並列で作業可能な構造にする
5. **パフォーマンス最適化**: 計算コストを最小化し、60fpsを維持する

### 1.3 スコープ

#### 修正対象
- `src/components/home/welcome/welcomeJS.tsx`
- `src/components/home/welcome/catPositionConfig.json`

#### 主な変更点
- 設定ファイルへのパラメータ追加
- パラメータ計算ロジックの実装
- `createAnimation`関数の修正
- デバイス/向き切り替え時の処理改善

### 3.2 関数設計

#### 3.2.1 パラメータ計算関数群（新規実装）

##### A. 正規化関数

```typescript
/**
 * Y座標を0.0〜1.0の範囲に正規化する
 *
 * @param finalPositionY - 最終落下位置のY座標（px）
 * @param minY - Y座標の最小値（px）
 * @param maxY - Y座標の最大値（px）
 * @returns 正規化されたY座標（0.0〜1.0）、範囲外の場合はクランプされる
 *
 * 計算式: (finalPositionY - minY) / (maxY - minY)
 *
 * 例:
 *   normalizePosition(30, 0, 60) => 0.5
 *   normalizePosition(0, 0, 60) => 0.0
 *   normalizePosition(60, 0, 60) => 1.0
 */
function normalizePosition(
  finalPositionY: number,
  minY: number,
  maxY: number
): number {
  // ゼロ除算を回避（minY === maxYの場合）
  if (maxY === minY) {
    return 0.5; // 中間値を返す
  }

  // 正規化計算
  const normalized = (finalPositionY - minY) / (maxY - minY);

  // 0.0〜1.0の範囲にクランプ
  return Math.max(0, Math.min(1, normalized));
}
```

**実装根拠:**
- 仕様書2.2.2、2.2.3の正規化式に基づく
- ゼロ除算エラーを防ぐため、minY === maxYの場合は0.5を返す
- 範囲外の値が入力された場合でも安全に動作するようクランプする

##### B. Amplitude（振幅）計算関数

```typescript
/**
 * 正規化されたY座標に基づいて揺れの振幅を計算する
 *
 * @param normalizedY - 正規化されたY座標（0.0〜1.0）
 * @param minAmplitude - 最小振幅（px）
 * @param maxAmplitude - 最大振幅（px）
 * @returns 計算された振幅（px）
 *
 * 計算式: minAmplitude + (maxAmplitude - minAmplitude) * normalizedY
 *
 * 物理的意味:
 *   上端（normalizedY=0）: 小さく揺れる
 *   下端（normalizedY=1）: 大きく揺れる
 *
 * 例（Portrait モード）:
 *   calculateAmplitude(0.0, 3.3, 10) => 3.3px
 *   calculateAmplitude(0.5, 3.3, 10) => 6.65px
 *   calculateAmplitude(1.0, 3.3, 10) => 10px
 */
function calculateAmplitude(
  normalizedY: number,
  minAmplitude: number,
  maxAmplitude: number
): number {
  return minAmplitude + (maxAmplitude - minAmplitude) * normalizedY;
}
```

**実装根拠:**
- 仕様書2.2.2の計算式に基づく
- 線形補間により、位置に応じた滑らかな変化を実現

##### C. Frequency（周波数）計算関数

```typescript
/**
 * 正規化されたY座標に基づいて揺れの周波数を計算する
 *
 * @param normalizedY - 正規化されたY座標（0.0〜1.0）
 * @param minFrequency - 最小周波数（遅い）
 * @param maxFrequency - 最大周波数（速い）
 * @returns 計算された周波数
 *
 * 計算式: maxFrequency - (maxFrequency - minFrequency) * normalizedY
 *
 * 物理的意味:
 *   上端（normalizedY=0）: 速く揺れる（周波数大）
 *   下端（normalizedY=1）: ゆっくり揺れる（周波数小）
 *
 * 例（Portrait モード）:
 *   calculateFrequency(0.0, 0.01, 0.05) => 0.05（速い）
 *   calculateFrequency(0.5, 0.01, 0.05) => 0.03（中間）
 *   calculateFrequency(1.0, 0.01, 0.05) => 0.01（遅い）
 */
function calculateFrequency(
  normalizedY: number,
  minFrequency: number,
  maxFrequency: number
): number {
  return maxFrequency - (maxFrequency - minFrequency) * normalizedY;
}
```

**実装根拠:**
- 仕様書2.2.2の計算式に基づく
- 逆線形補間により、下に行くほど周波数が小さくなる（ゆっくり揺れる）

##### D. BounceFactor（バウンド係数）計算関数

```typescript
/**
 * 正規化されたY座標に基づいてバウンド係数を計算する
 *
 * @param normalizedY - 正規化されたY座標（0.0〜1.0）
 * @param minBounce - 最小バウンド係数
 * @param maxBounce - 最大バウンド係数
 * @returns 計算されたバウンド係数
 *
 * 計算式: minBounce + (maxBounce - minBounce) * normalizedY
 *
 * 物理的意味:
 *   上端（normalizedY=0）: 小さく跳ねる
 *   下端（normalizedY=1）: 大きく跳ねる
 *
 * 例（Portrait モード）:
 *   calculateBounceFactor(0.0, 0.7, 0.85) => 0.70
 *   calculateBounceFactor(0.5, 0.7, 0.85) => 0.775
 *   calculateBounceFactor(1.0, 0.7, 0.85) => 0.85
 */
function calculateBounceFactor(
  normalizedY: number,
  minBounce: number,
  maxBounce: number
): number {
  return minBounce + (maxBounce - minBounce) * normalizedY;
}
```

**実装根拠:**
- 仕様書2.2.2の計算式に基づく
- 線形補間により、位置に応じた滑らかな変化を実現

##### E. 統合パラメータ計算関数

```typescript
/**
 * アニメーションパラメータを統合的に計算する
 *
 * @param config - キャラクター設定（catPositionConfig.jsonから取得）
 * @param isPortrait - portraitモードかどうか
 * @returns 計算されたアニメーションパラメータ
 *
 * ロジック:
 * 1. 設定ファイルにamplitude等が存在する場合はそれを使用
 * 2. 存在しない場合は、finalPositionYから動的に計算
 * 3. isPortraitに応じて適切なパラメータ範囲を選択
 */
interface AnimationParams {
  amplitude: number;
  frequency: number;
  bounceFactor: number;
  finalPositionY: number;
}

function getAnimationParams(
  config: CharacterConfig,
  isPortrait: boolean
): AnimationParams {
  const finalPositionY = config.finalPositionY;

  // 設定ファイルに明示的にパラメータが存在する場合はそれを使用
  if (config.amplitude !== undefined &&
      config.frequency !== undefined &&
      config.bounceFactor !== undefined) {
    return {
      amplitude: config.amplitude,
      frequency: config.frequency,
      bounceFactor: config.bounceFactor,
      finalPositionY: finalPositionY,
    };
  }

  // パラメータ範囲を設定
  let minY: number, maxY: number;
  let minAmplitude: number, maxAmplitude: number;
  let minFrequency: number, maxFrequency: number;
  let minBounce: number, maxBounce: number;

  if (isPortrait) {
    // Portrait モード用パラメータ範囲
    minY = 0;
    maxY = 60;
    minAmplitude = 3.3;
    maxAmplitude = 10;
    minFrequency = 0.01;
    maxFrequency = 0.05;
    minBounce = 0.7;
    maxBounce = 0.85;
  } else {
    // Landscape/PC モード用パラメータ範囲
    // 注意: 現在の実装ではminY=maxY=50のため、正規化は常に0.5になる
    // 将来的にfinalPositionYが変化する場合は、この範囲を調整する
    minY = 50;
    maxY = 50;
    minAmplitude = 7;
    maxAmplitude = 20;
    minFrequency = 0.01;
    maxFrequency = 0.05;
    minBounce = 0.7;
    maxBounce = 0.85;
  }

  // Y座標を正規化
  const normalizedY = normalizePosition(finalPositionY, minY, maxY);

  // 各パラメータを計算
  const amplitude = calculateAmplitude(normalizedY, minAmplitude, maxAmplitude);
  const frequency = calculateFrequency(normalizedY, minFrequency, maxFrequency);
  const bounceFactor = calculateBounceFactor(normalizedY, minBounce, maxBounce);

  return {
    amplitude,
    frequency,
    bounceFactor,
    finalPositionY,
  };
}
```

**実装根拠:**
- 設定ファイルの明示的なパラメータを優先することで、将来的な拡張性を確保
- portraitモードとlandscape/PCモードで異なるパラメータ範囲を使用
- 仕様書2.2.2、2.2.3のパラメータ範囲に基づく

#### 3.2.2 createAnimation 関数の修正

**現在の実装（抜粋）:**
```typescript
const createAnimation = useCallback((
  element: HTMLElement,
  finalPositionY: number,
  amplitude: number,
  frequency: number,
  gravity = 1.3,
  bounceFactor = 0.7,
  baseOffsetX = 0,
  baseOffsetY = 0
) => {
  // ... アニメーション処理
}, [updatePosition]);
```

**修正後の実装:**
```typescript
const createAnimation = useCallback((
  element: HTMLElement,
  config: CharacterConfig,
  baseOffsetX = 0,
  baseOffsetY = 0
) => {
  const { isMobileOrTablet } = getDeviceInfo();
  const deviceKey = getDeviceConfigKey();
  const isPortrait = deviceKey.includes('portrait');

  // パラメータを計算または設定ファイルから取得
  const params = getAnimationParams(config, isPortrait);

  // portraitモード時のみパラメータを調整（既存のロジックを維持）
  const adjustedFinalPositionY = isPortrait
    ? params.finalPositionY / 2
    : params.finalPositionY;
  const adjustedAmplitude = isPortrait
    ? params.amplitude / 1.5
    : params.amplitude;

  // 固定値
  const gravity = 1.3;

  // 初期位置をportraitモード時のみ調整
  let positionY = isPortrait ? -500 : -1150;
  let velocity = 0;
  let angle = -1;
  let isBouncing = true;
  let animationId: number | null = null;

  // アニメーションの開始
  const startAnimation = () => {
    velocity += gravity;
    positionY += velocity;

    if (positionY >= adjustedFinalPositionY) {
      positionY = adjustedFinalPositionY;
      velocity = -velocity * params.bounceFactor; // 計算されたバウンド係数を使用

      if (Math.abs(velocity) < 1) {
        isBouncing = false;
      }
    }

    angle += params.frequency; // 計算された周波数を使用
    const swayOffset = Math.sin(angle) * adjustedAmplitude;

    element.style.transform = `translate(${swayOffset + baseOffsetX}px, ${positionY + baseOffsetY}px)`;

    // 毎フレームスポットライト位置を更新（高フレームレート）
    updatePosition();

    animationId = requestAnimationFrame(startAnimation);
  };

  // クリックイベントハンドラ（変更なし）
  const onClick = (event: MouseEvent) => {
    const welcome = document.querySelector('.welcome');
    if (!(welcome && welcome.contains(event.target as Node))) {
      return;
    }

    if (animationId !== null) cancelAnimationFrame(animationId);

    velocity = 0;
    positionY = isPortrait ? -500 : -1150;
    isBouncing = true;
    angle = 0;

    animationId = requestAnimationFrame(startAnimation);
  };

  // リサイズイベントハンドラ（変更なし）
  const handleResize = () => {
    const newDeviceKey = getDeviceConfigKey();
    const newIsPortrait = newDeviceKey.includes('portrait');

    // portrait状態が変わった場合のみ再調整
    if (newIsPortrait !== isPortrait) {
      if (animationId !== null) cancelAnimationFrame(animationId);
      velocity = 0;
      positionY = newIsPortrait ? -500 : -1150;
      isBouncing = true;
      angle = 0;
      animationId = requestAnimationFrame(startAnimation);
    }
  };

  window.addEventListener('click', onClick);
  window.addEventListener('resize', handleResize);
  animationId = requestAnimationFrame(startAnimation);

  return () => {
    window.removeEventListener('click', onClick);
    window.removeEventListener('resize', handleResize);
    if (animationId !== null) cancelAnimationFrame(animationId);
  };
}, [updatePosition]);
```

**変更点:**
1. 引数を簡素化: 個別のパラメータではなく、`CharacterConfig`オブジェクトを受け取る
2. `getAnimationParams()`を呼び出してパラメータを取得
3. 計算されたパラメータ（`params.amplitude`, `params.frequency`, `params.bounceFactor`）を使用
4. 既存のportrait調整ロジック（`/ 2`, `/ 1.5`）は維持

```typescript
// 型定義
type Props = {
    isDarkMode: boolean;
};

interface SpotlightPosition {
    x: number;
    y: number;
    r: number;
}

// ここに追加
interface CharacterConfig {
    offsetX: number;
    offsetY: number;
    finalPositionY: number;
    amplitude?: number;
    frequency?: number;
    bounceFactor?: number;
}

interface AnimationParams {
    amplitude: number;
    frequency: number;
    bounceFactor: number;
    finalPositionY: number;
}

// パラメータ計算関数群
function normalizePosition(
    finalPositionY: number,
    minY: number,
    maxY: number
): number {
    if (maxY === minY) {
        return 0.5;
    }
    const normalized = (finalPositionY - minY) / (maxY - minY);
    return Math.max(0, Math.min(1, normalized));
}

function calculateAmplitude(
    normalizedY: number,
    minAmplitude: number,
    maxAmplitude: number
): number {
    return minAmplitude + (maxAmplitude - minAmplitude) * normalizedY;
}

function calculateFrequency(
    normalizedY: number,
    minFrequency: number,
    maxFrequency: number
): number {
    return maxFrequency - (maxFrequency - minFrequency) * normalizedY;
}

function calculateBounceFactor(
    normalizedY: number,
    minBounce: number,
    maxBounce: number
): number {
    return minBounce + (maxBounce - minBounce) * normalizedY;
}

function getAnimationParams(
    config: CharacterConfig,
    isPortrait: boolean
): AnimationParams {
    const finalPositionY = config.finalPositionY;

    if (config.amplitude !== undefined &&
        config.frequency !== undefined &&
        config.bounceFactor !== undefined) {
        return {
            amplitude: config.amplitude,
            frequency: config.frequency,
            bounceFactor: config.bounceFactor,
            finalPositionY: finalPositionY,
        };
    }

    let minY: number, maxY: number;
    let minAmplitude: number, maxAmplitude: number;
    let minFrequency: number, maxFrequency: number;
    let minBounce: number, maxBounce: number;

    if (isPortrait) {
        minY = 0;
        maxY = 60;
        minAmplitude = 3.3;
        maxAmplitude = 10;
        minFrequency = 0.01;
        maxFrequency = 0.05;
        minBounce = 0.7;
        maxBounce = 0.85;
    } else {
        minY = 50;
        maxY = 50;
        minAmplitude = 7;
        maxAmplitude = 20;
        minFrequency = 0.01;
        maxFrequency = 0.05;
        minBounce = 0.7;
        maxBounce = 0.85;
    }

    const normalizedY = normalizePosition(finalPositionY, minY, maxY);
    const amplitude = calculateAmplitude(normalizedY, minAmplitude, maxAmplitude);
    const frequency = calculateFrequency(normalizedY, minFrequency, maxFrequency);
    const bounceFactor = calculateBounceFactor(normalizedY, minBounce, maxBounce);

    return {
        amplitude,
        frequency,
        bounceFactor,
        finalPositionY,
    };
}

export default function WelcomeJS({ isDarkMode }: Props) {
    // コンポーネント本体
    // ...
}

const createAnimation = useCallback((
    element: HTMLElement,
    config: CharacterConfig,
    baseOffsetX = 0,
    baseOffsetY = 0
) => {
    const { isMobileOrTablet } = getDeviceInfo();
    const deviceKey = getDeviceConfigKey();
    const isPortrait = deviceKey.includes('portrait');

    // パラメータを計算または設定ファイルから取得
    const params = getAnimationParams(config, isPortrait);

    // portraitモード時のみパラメータを調整（既存のロジックを維持）
    const adjustedFinalPositionY = isPortrait
        ? params.finalPositionY / 2
        : params.finalPositionY;
    const adjustedAmplitude = isPortrait
        ? params.amplitude / 1.5
        : params.amplitude;

    // 固定値
    const gravity = 1.3;

    // 初期位置をportraitモード時のみ調整
    let positionY = isPortrait ? -500 : -1150;
    let velocity = 0;
    let angle = -1;
    let isBouncing = true;
    let animationId: number | null = null;

    // アニメーションの開始
    const startAnimation = () => {
        velocity += gravity;
        positionY += velocity;

        if (positionY >= adjustedFinalPositionY) {
            positionY = adjustedFinalPositionY;
            velocity = -velocity * params.bounceFactor; // 計算されたバウンド係数を使用

            if (Math.abs(velocity) < 1) {
                isBouncing = false;
            }
        }

        angle += params.frequency; // 計算された周波数を使用
        const swayOffset = Math.sin(angle) * adjustedAmplitude;

        element.style.transform = `translate(${swayOffset + baseOffsetX}px, ${positionY + baseOffsetY}px)`;

        updatePosition();

        animationId = requestAnimationFrame(startAnimation);
    };

    // onClick, handleResizeは変更なし
    const onClick = (event: MouseEvent) => {
        const welcome = document.querySelector('.welcome');
        if (!(welcome && welcome.contains(event.target as Node))) {
            return;
        }

        if (animationId !== null) cancelAnimationFrame(animationId);

        velocity = 0;
        positionY = isPortrait ? -500 : -1150;
        isBouncing = true;
        angle = 0;

        animationId = requestAnimationFrame(startAnimation);
    };

    const handleResize = () => {
        const newDeviceKey = getDeviceConfigKey();
        const newIsPortrait = newDeviceKey.includes('portrait');

        if (newIsPortrait !== isPortrait) {
            if (animationId !== null) cancelAnimationFrame(animationId);
            velocity = 0;
            positionY = newIsPortrait ? -500 : -1150;
            isBouncing = true;
            angle = 0;
            animationId = requestAnimationFrame(startAnimation);
        }
    };

    window.addEventListener('click', onClick);
    window.addEventListener('resize', handleResize);
    animationId = requestAnimationFrame(startAnimation);

    return () => {
        window.removeEventListener('click', onClick);
        window.removeEventListener('resize', handleResize);
        if (animationId !== null) cancelAnimationFrame(animationId);
    };
}, [updatePosition]);
```

### 6.2 計算エラー

**エラーケース:**

**対処方法:**
```typescript
function normalizePosition(
  finalPositionY: number,
  minY: number,
  maxY: number
): number {
  // NaN, Infinityのチェック
  if (!Number.isFinite(finalPositionY) ||
      !Number.isFinite(minY) ||
      !Number.isFinite(maxY)) {
    console.error('無効な数値が渡されました');
    return 0.5; // 安全なデフォルト値
  }

  if (maxY === minY) {
    return 0.5;
  }

  const normalized = (finalPositionY - minY) / (maxY - minY);
  return Math.max(0, Math.min(1, normalized));
}
```

### 7.2 DOM操作の最小化

**方針:**
- `getBoundingClientRect()`の呼び出しを必要最小限にする
- リサイズ時のみ位置を再計算する
- アニメーションフレームごとのDOM読み取りを避ける

**実装状況:**
- 現在の実装では毎フレーム`updatePosition()`を呼び出している
- これにより`getBoundingClientRect()`が頻繁に呼ばれる可能性がある
- ただし、スポットライトの追従には必要な処理

**最適化案（将来的に検討）:**
```typescript
// キャラクター位置のキャッシュ
let cachedCatARect: DOMRect | null = null;
let cachedCatBRect: DOMRect | null = null;
let cacheInvalidated = true;

const updatePosition = useCallback(() => {
  // キャッシュが無効化されている場合のみ再計算
  if (cacheInvalidated) {
    const catA = document.querySelector('.catA') as HTMLElement | null;
    const catB = document.querySelector('.catB') as HTMLElement | null;
    if (catA) cachedCatARect = catA.getBoundingClientRect();
    if (catB) cachedCatBRect = catB.getBoundingClientRect();
    cacheInvalidated = false;
  }

  // キャッシュされた値を使用
  if (cachedCatARect && spotlightR) {
    spotlightR.style.top = `${window.scrollY + cachedCatARect.bottom - cachedCatARect.height * 0.5 + spotlightRConfig.offsetTop}px`;
    // ...
  }
}, []);

// リサイズ時にキャッシュを無効化
const handleResize = () => {
  cacheInvalidated = true;
  updatePosition();
};
```

### 7.3 スポットライト描画の最適化

**現在の最適化:**
- マウス移動が2px未満の場合はスキップ（閾値処理）
- `requestAnimationFrame`で描画を間引き
- `isAnimating`フラグで重複呼び出しを防止

**実装状況（既存）:**
```typescript
const onMouseMove = (e: MouseEvent) => {
  if (!isDarkMode) return;

  const dx = e.clientX - lastMousePosition.x;
  const dy = e.clientY - lastMousePosition.y;
  const distance = Math.sqrt(dx * dx + dy * dy);

  if (distance < 2) return; // 閾値未満はスキップ

  lastMousePosition = { x: e.clientX, y: e.clientY };
  mouseSpot = { x: e.clientX, y: e.clientY, r: window.innerHeight / 2 };
  spotlightsRef.current[0] = mouseSpot;

  if (isAnimating) return; // 重複呼び出しを防止
  isAnimating = true;

  if (animationFrameId) cancelAnimationFrame(animationFrameId);
  animationFrameId = requestAnimationFrame(() => {
    drawSpotlights(spotlightsRef.current);
    isAnimating = false;
  });
};
```

**追加の最適化（将来的に検討）:**
- オフスクリーンキャンバスの使用
- WebGLによる描画（大規模なスポットライト配列の場合）

const easeInOutQuad: EasingFunction = (t) => {
  return t < 0.5 ? 2 * t * t : -1 + (4 - 2 * t) * t;
};

const easeOutBounce: EasingFunction = (t) => {
  const n1 = 7.5625;
  const d1 = 2.75;
  if (t < 1 / d1) {
    return n1 * t * t;
  } else if (t < 2 / d1) {
    return n1 * (t -= 1.5 / d1) * t + 0.75;
  } else if (t < 2.5 / d1) {
    return n1 * (t -= 2.25 / d1) * t + 0.9375;
  } else {
    return n1 * (t -= 2.625 / d1) * t + 0.984375;
  }
};

  maxAmplitude: number,
  easing: EasingFunction = (t) => t // デフォルトは線形

  const easedY = easing(normalizedY);

## 10. リスクと対策

### 10.1 技術的リスク

#### Risk 1: パフォーマンス劣化
**リスク内容:**
- 毎フレームのパラメータ計算による負荷増加
- 60fpsの維持が困難になる

**影響度:** 中

**対策:**
- パラメータ計算は初期化時のみ実行（実装済み）
- パフォーマンステストで検証
- 必要に応じてスポットライト更新頻度を下げる

#### Risk 2: ブラウザ互換性
**リスク内容:**
- `Math.sin()`, `requestAnimationFrame()`の動作がブラウザによって異なる可能性
- 古いブラウザでの動作不良

**影響度:** 低

**対策:**
- 主要ブラウザ（Chrome, Firefox, Safari, Edge）でテスト
- Polyfillの追加（必要に応じて）

#### Risk 3: 設定ファイルの破損
**リスク内容:**
- JSONの構文エラー
- 必須フィールドの欠落

**影響度:** 中

**対策:**
- TypeScriptの型チェックを活用
- エラーハンドリングの実装
- デフォルト値の設定

### 10.2 運用リスク

#### Risk 4: パラメータ調整の難しさ
**リスク内容:**
- 非エンジニアが設定を変更する際にミスする可能性
- 適切なパラメータ値の判断が難しい

**影響度:** 低

**対策:**
- 設定ファイルにコメントを追加（JSONはコメント不可のため、別途ドキュメント作成）
- バリデーションツールの作成（将来的に検討）

#### Risk 5: デバイス判定の誤り
**リスク内容:**
- 新しいデバイスやブラウザで判定ロジックが動作しない
- タッチデバイスの誤検知

**影響度:** 中

**対策:**
- デバイス判定ロジックを定期的に見直す
- ユーザーエージェント情報のログ収集（将来的に検討）
